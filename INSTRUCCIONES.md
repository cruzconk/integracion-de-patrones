# Project Instructions

## Open the project

Extract the ZIP file and open the `workproj` folder in Eclipse, IntelliJ IDEA, or Visual Studio Code.

## Run with an IDE

Use `com.company.documents.Main` as the main class.

## Run from the terminal

```bash
javac -d out $(find src/main/java -name "*.java")
java -cp out com.company.documents.Main
```

The project uses standard Java and does not require external libraries.

## Expected result

The program demonstrates all six required design patterns and finishes with:

```text
=== DEMO COMPLETED SUCCESSFULLY ===
```
